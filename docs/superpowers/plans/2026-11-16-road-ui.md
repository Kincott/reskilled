# The road interface: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Reskilled's overview, skill view and options screen with one tabbed window: Home (Steve, stats,
skills grouped by focus), a road per skill (gear above, perks below in advancement frames, a dock), and Options.

**Architecture:** The data gains optional `icon` (perks, locks) and `color` (skills) fields carried to clients.
The client's `View` becomes a `Tab`; each screen gets its own module with a pure layout function (rects only,
tested) and a draw function, and clicks map to hit areas from the layout as today. Requests, rules and checks
behind the buttons do not change.

**Tech Stack:** Rust (Horizon trait mod, pinned commit in `reskilled/HORIZON_PIN.md`), `skills_core` for data,
Horizon `Host` HUD helpers (`fill`, `quad`, `text`, `sprite`, `tiled_sprite`, `item`), preview tests rendered by
`reskilled/tools/preview.py`.

**Spec:** `docs/superpowers/specs/2026-11-16-road-ui-design.md` (mockups in `2026-11-16-road-ui/`, drawn by
`reskilled/tools/mockups/road.py`, whose colours and sizes the code follows).

## Global Constraints

- GUI sizes: everything fits and no two texts overlap at 320 x 240 and 427 x 240 (`SMALLEST`, `USUAL` in
  `client/preview.rs`).
- Window: centred, width the GUI width less 16 up to 383, height the GUI height less the tabs (28) and an 8 margin.
- Colours (ARGB): body `0xFF1A1D26`, card `0xFF232733`, card hover `0xFF2B3040`, inset `0xFF0F1116`, brass light
  `0xFFE6C36A`, brass `0xFFAD8436`, brass dark `0xFF5A4116`, mastered row `0xFF332B1D`; text gold `0xF2C14E`, gray
  `0xA8ADB8`, dim `0x6C7280`, green `0x7FDB5A`, red `0xFF6B5E`.
- Shipped skill colours: Mining `#8FA6B8`, Melee `#D9534A`, Defense `#6E8FD9`, Arcane `#B07CF2`, Gathering
  `#7FC75A`, Agility `#5AD1C7`, Building `#D98C4A`, Ranged `#D9C24A`.
- Vanilla sprites (GUI atlas): `gui/sprites/advancements/{task,goal,challenge}_frame_{obtained,unobtained}`
  (26 x 26), `gui/sprites/container/slot`; backdrop `gui/advancements/backgrounds/stone` (16 x 16 tiles, darkened
  with `0x9E0B0C10`).
- Data stays format 1: every new field is optional; data without them loads and draws.
- Every player-facing string is a translation key with its English in `text.rs` and `en_us.json` (a test keeps them
  equal).
- Commits: one per task, no AI attribution line (the user's rule for this repository).

## Review Focus

1. **The smallest GUI (320 x 240).** Every screen fits: Task 9's preview test checks all screens at both sizes.
2. **A pack's own shape:** more than eight skills (tabs scroll), two perks at one level (side by side), a top level
   other than 32 (the road scales; above 64 it scrolls), a skill with no perks or no labelled locks (an empty road
   draws). Tests in Tasks 4 and 6.
3. **A skill in no focus area** goes under "Other" on Home; a pack with no focus areas shows one ungrouped list.
   Test in Task 5.
4. **Before the definitions arrive** every tab shows "Waiting for the server..." and clicks do nothing. Test in
   Task 4.
5. **Clicks that must do nothing:** a raise the player cannot pay, Unlock on a locked perk, Area on an unowned perk,
   a rule row for a non-operator. Tests in Tasks 5, 6, 7.
